# NANO // OXO: REALMS — быстрый старт

Игра действительно работает **на Arduino Nano (ATmega328P)**: все клетки, правила, решения бота, боссы и уровни живут на микроконтроллере. Программа на Rust — только красивое терминальное окно (TUI), которое отправляет нажатия по USB Serial и отображает состояние.

## Один ZIP и `setup.ps1` (Windows)

**Всё уже внутри одного архива.** Распакуй его целиком; не копируй `setup.ps1` отдельно от папок `tui` и `firmware`.

Открой PowerShell в папке с распакованными файлами и выполни:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1 -Port COM3
```

Скрипт проверит Rust/Cargo, соберёт Rust-приложение и запустит игру через `COM3`. Порт можно не указывать: при единственном порте он выбирается автоматически, при нескольких — запрашивается. Если Rust отсутствует, скрипт предложит установить официальный Rustup через `winget` (только с твоего согласия).

**Прошивка:** если ты уже загрузил `.ino` на Nano, повторная загрузка необязательна. Чтобы прошить свежую версию прямо из PowerShell, используй:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1 -Port COM3 -Flash
```

Нужен Arduino CLI; если его нет, скрипт предложит установку через `winget`. Для старого загрузчика Nano добавь `-OldBootloader`. При желании можно прошить вручную из Arduino IDE (`firmware/NanoOXO/NanoOXO.ino`). Перед запуском игры **закрой Serial Monitor**, иначе COM-порт окажется занят.

Дополнительные режимы: `-Probe` — проверить Serial и выполнить тестовый ход; `-NoRun` — только сборка. `-ExecutionPolicy Bypass` действует только для этой команды, не меняет глобальные настройки Windows. Для первой сборки Cargo нужен интернет.

## Сначала прошивка

1. Установи **Arduino IDE**.
2. Открой `firmware/NanoOXO/NanoOXO.ino`.
3. Выбери плату **Arduino Nano**, процессор **ATmega328P**, нужный порт.
4. Если прошивка не загружается — попробуй **ATmega328P (Old Bootloader)**.
5. Нажми **Upload**. После загрузки обязательно **закрой Serial Monitor**, иначе Rust не сможет открыть порт.

## Потом терминал на Rust

Нужен установленный Rust (`rustup` и `cargo`). Открой терминал **в папке `tui`**:

```bash
cargo run --release -- --list
```

Это покажет COM-порты / USB-порты. Запусти с нужным:

**Windows:**

```powershell
cargo run --release -- --port COM5
```

**Linux:**

```bash
cargo run --release -- --port /dev/ttyUSB0
```

**macOS:**

```bash
cargo run --release -- --port /dev/cu.usbserial-XXXX
```

Номер COM5 — просто пример, подставь свой. При единственном доступном порте можно запустить просто `cargo run --release`.

Подключай Nano нормальным USB-кабелем с передачей данных. Скорость прошивки и терминала: **115200 бод**. Желательно окно терминала шириной не менее 85 символов.

## Клавиши

- **Стрелки** — перемещение по полю.
- **Enter / Пробел** — поставить X.
- **1–9** — выбрать клетку и поставить X в обычных крестиках-ноликах.
- **R** — перезапустить уровень/бой (включая все жизни босса).
- **N** — перейти на следующий уровень после победы.
- **F1–F5** — выбрать уже открытый уровень.
- **S** — запросить состояние заново.
- **Q / Escape** — выйти.

## Пять уровней

1. **FIRST CONTACT** — обычные 3×3, простой противник.
2. **THE GATEKEEPER** — босс в 3×3, нужно победить два раунда.
3. **NINE REALMS** — настоящие большие крестики-нолики (9 мини-полей, 81 клетка), по мотивам [твоего OXO](https://oxo-w3r.vercel.app/).
4. **THE ARCHON** — сложный босс на большом поле, две победы.
5. **FINAL KERNEL** — финальный босс на большом поле, три победы.

В больших крестиках-ноликах клетка, в которую ходишь, определяет мини-поле, куда обязан ходить противник. Если выбранное мини-поле уже закрыто, можно ходить в любое незакрытое. Выигрываешь три мини-поля в ряд — выигрываешь раунд.

**Открытые уровни сохраняются в EEPROM Arduino** и остаются после отключения питания. Текущий незавершённый бой не сохраняется.

Подробнее про механику, команды Serial, тесты и неполадки — в `README.md`.

> В этом окружении проверена логика Arduino на C++-симуляторе, включая 125 случайных полных партий. Проверки на физической Nano и сборки Rust здесь нет: инструменты Arduino AVR и Cargo недоступны, поэтому исходники нужно собрать и прошить на своём компьютере.


## Исправление проблемы «поля не помечаются» (v1.1)

Если в Arduino IDE команда `MOVE 0` работает, а в TUI клетка остаётся пустой, используй новый `tui/src/main.rs` из архива. На первом этапе **прошивать Arduino заново не обязательно**.

Перед запуском закрой Serial Monitor (порт может открывать только одна программа):

```powershell
cd tui
cargo run --release -- --probe COM3
```

Диагностический режим работает без TUI, отправляет `SYNC`, `MOVE 0`, выводит принятые строки и число крестиков и ноликов. Он делает один тестовый ход. Если написано `DECODED: level 1, X: 1, O: 1`, Serial-обмен работает.

Затем запусти игру:

```powershell
cargo run --release -- --port COM3
```

После нажатия `1` смотри диагностические строки внизу терминала:

- `DEBUG KEY` — какую кнопку увидел Rust.
- `TX` — что отправил в Arduino, например `MOVE 0`.
- `RX` — что пришло от Arduino, например `STATE: X=1 O=1`.

Клавиша `D` скрывает или возвращает диагностические строки. Если `TX` меняется, но Arduino отвечает ошибками или молчит, дополнительно обнови `.ino` из архива и загрузи прошивку заново. Скорость остаётся **115200**.
